# Hints

## General

- An integer value can be defined as one or more consecutive digits.
- All four methods are defined inside the `Lasagna` object, indented below it.

## 1. Define the expected oven time in minutes

- You need to define a [method][methods] without any parameters.
- The method returns an [integer][built-in-types].
- The stub already contains this method: replace `???` with its body.

## 2. Calculate the remaining oven time in minutes

- You need to define a [method][methods] with a single parameter.
- The method's parameter is an [integer][built-in-types], and so is the value it returns.
- You can call the method you defined in the previous task.
- You can use the `-` operator to subtract values.

## 3. Calculate the preparation time in minutes

- You need to define a [method][methods] with a single parameter.
- The method's parameter is an [integer][built-in-types], and so is the value it returns.
- You can use the `*` operator to multiply values.

## 4. Calculate the elapsed time in minutes

- You need to define a [method][methods] with two parameters.
- The method's parameters are [integers][built-in-types], and so is the value it returns.
- You can call one of the other methods you've defined previously.
- You can use the `+` operator to add values.

[methods]: https://docs.scala-lang.org/scala3/book/taste-methods.html
[built-in-types]: https://docs.scala-lang.org/scala3/book/first-look-at-types.html
